# Versão integrada — instalação e limites

Faça backup do banco e da pasta do projeto. Extraia sobre uma cópia do projeto, preservando .git e .env. Execute npm install, npm test e npm start. A inicialização cria a tabela finance_records de forma aditiva; as tabelas existentes devem estar configuradas. A conta PostgreSQL precisa de permissão CREATE. Não publique .env.

Esta versão integra as quatro telas e mantém a API anterior. Novos registros usam uma tabela por usuário/tipo/id com JSONB e valores em centavos, não o modelo relacional definitivo do prompt. Itens de planejamento são gravados ao salvar o planejamento. Recorrências são registradas manualmente como pagas, com identificador mensal determinístico. Conquistas são avaliadas ao abrir Metas. Contribuições e atualização do acumulado ainda são duas operações, sem atomicidade; não considerar a implementação pronta para produção. O calendário de hábitos, histórico detalhado dos ciclos, migração relacional completa e validação de conquistas no servidor ainda estão pendentes. O layout usa a página Metas existente, sem o protótipo original. Testes unitários financeiros e sintaxe JS executados; integração com PostgreSQL, isolamento entre duas contas e testes de navegador não executados.
